# Security

StreamCore carries remote input and screen content between devices, so we take
security reports seriously.

## Reporting a problem

Email **security@codonic.dev** with a description, the affected version or
commit, and steps to reproduce. Please don't open a public issue.

We will acknowledge your report within a few days and keep you informed while
we fix it. We credit reporters in the release notes unless you ask us not to.

## Supported versions

StreamCore is pre-release. Only the latest commit on `main` receives fixes.
